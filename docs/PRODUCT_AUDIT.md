# 产品走查与优化记录

## 本轮结论

现有品牌方向和推荐页主视觉保留，优化重点从页面展示转向“找剧—看详情—选集—播放—追剧—回访”的产品闭环。

### 频道定位

- 推荐承担内容发现与运营组织，保留 Cover Flow，增加热榜和编辑精选。
- 短剧承担高效率找剧，使用轻量题材快捷筛选和可展开的状态、地区、排序筛选。
- 漫剧强调内容气质与更新节奏，使用横向精选头图、4:5 卡片和追更日历。
- 刷剧保持单列沉浸式上下滑发现，详情入口与追剧页形成回流。

### 补齐状态

- 搜索：推荐词、有结果、无结果。
- 筛选：复合筛选、结果计数、无结果与重置。
- 播放：加载、播放/暂停、失败与重试、选集。
- 用户：游客、登录、追剧列表、收藏空状态、观看记录。
- 网络：离线提示与缓存内容说明。
- 会员：游客/未开通状态与权益说明。
- 18+专区：年龄确认、进入、收藏与退出。

## 竞品参考原则

- 红果短剧官方产品说明强调单列推荐、剧场找剧、一键追剧、评论、预约和任意选集，说明短剧产品需要同时支持沉浸发现与高效率选剧。
- Netflix 官方把已保存、正在观看、最近观看等内容集中到 My Netflix，说明个人区应帮助用户快速回到已产生关系的内容。
- Netflix 新移动端设计强调简化导航和手机纵向内容发现，与本项目“首页找剧 + 刷剧沉浸流”的双路径一致。

本项目只吸收信息组织和交互原则，没有复制第三方品牌、配色、文案或运营组件。
