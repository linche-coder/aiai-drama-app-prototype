## 正式后端依赖

认证与邮箱验证、活动领取与邀请计奖、APP专享资格、会员报价与订单、支付与退款、积分签到与兑换、单集解锁、会员/体验生效、内容权限、评论、消息、工单、播放凭证和正式片源均依赖 `/api/v1`。接口失败时 APP 不产生本地成功状态。

## 风险与待办

- WEB 当前普通目录与18+目录均含预览/草稿内容，部分正式集数、类型、发布状态和授权信息仍待后端返回。
- 18+ WEB 基准的20部内容当前均为真人短剧预览、原创标记为否；因此“成人漫剧”“原创”频道会显示真实空状态。
- APP 为 Hash 路由；兼容路径表现为 `/#/path`，生产网关需要保持 SPA 回退。
- 支付和正式播放服务未接通时只能验收错误/重试状态，不能完成真实付款或播放。
