# 交接说明

## 页面和交互

- 首页：无页头 Logo；搜索框、会员按钮、推荐/短剧/漫剧频道、Cover Flow、可选续看记录、三组内容列表。
- Cover Flow：点击侧卡切换，左右拖动换片，手动操作后停止自动轮播；主卡点击及播放按钮继续使用原有剧目预览弹层。
- 开屏：直接使用 WEB 端分组 SVG 和原缓动语汇，显现与停留后仅整层淡出，没有飞向页头的阶段。
- 刷剧：原生 `video` 驱动纵向吸附流；当前项播放、离屏项暂停，支持暂停、双击点赞、收藏、评论抽屉、分享反馈和进度拖动。
- 底栏：18+ 图标未选中时使用 SVG mask 单色显示，选中时显示未改色的原始渐变 SVG。
- 搜索、会员、剧目预览、18+ 占位、追剧占位和我的占位继续沿用原路由/状态结构。

## 组件和数据边界

- 全局视觉参数集中在 `src/styles/app.css` 的 `:root`。
- 剧目数据仍来自 `src/data/dramas.ts`，没有更换业务内容。
- 新增刷剧页面组件 `src/components/ReelsScreen.tsx`；本次会话状态保存在 `sessionStorage`。
- 正式接入时需将 `VIDEO_SOURCE` 和计数替换为接口字段，并将点赞、收藏、评论、分享接入真实服务。

## 已验证

- `npm.cmd run build`。
- Chrome 自动化回归：开屏一次性与重播、首页 360/390/430 宽度、频道和 Cover Flow、搜索有/无结果、弹层、18+ 图标双状态、刷剧播放/暂停/上下切换/评论/会话状态、桌面演示控制。
- 验收结果由 `scripts/verify-prototype.mjs` 输出；截图在 `docs/screenshots/`。
