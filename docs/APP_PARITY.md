# APP 与 WEB 1.4.3 同步对照

| 业务 | APP 路由 | 同步结果 |
| --- | --- | --- |
| 首页 | `/` | 轮播、双节活动、继续观看、热门推荐、题材筛选、最新更新 |
| 刷剧 | `/reels` | 保留 APP 原生竖向信息流；数据只使用普通区目录 |
| 普通搜索 | `/search` | 只搜索普通区标题和题材 |
| 真人短剧 / AI漫剧 | `/videos`、`/shorts`、`/comics` | 映射到移动端频道 |
| 双节活动 | `/festival` | 任务、邀请、APP奖励、会员赠天数、奖励记录与失败重试 |
| 畅看会员 | `/membership` | ¥88 / ¥188 / ¥388 与 220 积分 ¥10.9；24小时体验 |
| 积分与签到 | `/me/points` | 永久积分、会员积分、签到、兑换、解锁与退款记录 |
| 18+专区 | `/18plus` | 年龄复选确认、20部横版内容、7张轮播（活动+6部内容） |
| 专区搜索 / 愿望榜 | `/18plus/search`、`/18plus/wishlist` | 专区隔离搜索；愿望榜仅当前会话保存 |
| 详情 / 播放 / 阅读 | `/detail/:id`、`/play/:id`、`/18plus/play/:id`、`/read/:id` | 权限、片源、凭证和空状态保留真实失败语义 |
| 追剧 | `/following`、`/me/favorites` | 使用同一份普通区追剧数据 |
| 账户 | `/account/*` | 账号登录、4—20位账号注册、确认密码、选填邮箱、真实邮件重置 |
| 订单 | `/checkout`、`/payment-result`、`/me/orders/*` | 只接受四个最新商品，状态以服务端为准 |
| 帮助与政策 | `/support/*`、`/help`、`/contact`、政策路由 | 最新会员、积分、年龄确认和反馈字段 |

已失效路由：`/free`、`/rankings`、`/collections`、`/collections/:id`、`/updates`、`/settings`。这些路径统一显示“页面已下线”，不再渲染旧内容。

普通内容的集数、更新状态、发布状态和访问权限在 WEB 基准中为未知或草稿时，APP 显示“状态待确认”“权限待服务确认”，不生成热度、地区、集数或完结状态。
